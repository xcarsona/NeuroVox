NeuroVox is an interpretable machine learning framework for identifying depression-related language through lexical biomarkers. Using TF-IDF features and a regularized logistic regression model, the system achieves approximately 76% validation accuracy on a publicly available mental health text dataset while preserving feature-level interpretability. Sanity-check experiments, including label shuffling and affective-language ablation, confirm that the model learns meaningful linguistic patterns rather than dataset artifacts. Analysis of model coefficients reveals interpretable lexical markers aligned with established psychological constructs such as anxiety and rumination. Error analysis highlights the difficulty of distinguishing depression from related affective states, emphasizing the need for cautious interpretation. NeuroVox is intended as a research and analytical tool, prioritizing transparency, reproducibility, and ethical responsibility over clinical deployment.
